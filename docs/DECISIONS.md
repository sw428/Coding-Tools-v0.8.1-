# DECISIONS — 判断の履歴

ここには**いつ・なぜその設計にしたか**を残す。未来の判断は追記し、過去の意思決定を消さない。

## 2026-10-25時点までに採用した方針

### D-001 通常コピペのショートカットを奪わない

- 理由：他の拡張と競合したり、普段のテキスト編集に予期せぬ変換が起きる可能性を下げる。
- 決定：Ctrl+C/VとCmd+C/VにはCoding Toolsを割り当てず、専用コマンドのみを使用する。

### D-002 保存枠は2つにする

- 理由：頻繁な相互ジャンプのショートカットに操作領域を振り分ける。
- 決定：番号1・2を保存枠、3・4をHTML/CSSジャンプに使う。

### D-003 ジャンプは確認画面を出さない

- 理由：読み取り専用の移動に毎回確認するコストをかけない。
- 決定：第一候補に直接移動し、追加候補はTab / Shift+Tab、Escで終了。

### D-004 変更を伴うCSS自動配置は分離

- 理由：誤配置の影響があるため、ジャンプの処理と混ぜない。
- 決定：専用コマンドと確認・履歴機能を使う。

### D-005 使用履歴とソース管理を分離

- 理由：個人学習データや職場コードをリポジトリに持ち込まない。
- 決定：Diff履歴は外部保存。Gitは拡張のソース・仕様・テストを管理する。

## 2026-10-25 — CSS自動配置を安全側に制限（v0.8.2 β）

- 既存ルールを変更せず、空のルール1つのみ追加する。
- 構文解析と既存ASTの保存を検査し、失敗時は中止する。
- 適用前にDiffプレビューを表示。最終確認OFFでも安全検査は必須。
- SCSS/LESSは解析を保証できないため自動配置対象外。
- 理由：移動・コピー機能の安定性を保ち、自動配置によるCSS破損リスクを低減するため。

## 2026-10-26 — コピー枠のステータスバー表示とコピーの統合

- 前・次のクラスの追加選択コマンドとキーを削除する。通常の前後移動は残す。
- 枠1・2を下部ステータスバーに常時表示し、保存内容の短いプレビューとコピー／貼り付けメニューを提供する。空枠でもコピーできる。
- 枠のコピー・貼り付け4コマンドはキー割り当て用に残し、パレットから非表示にする。旧9・10の枠選択コマンドは削除する。
- 旧11・12の独立コマンドを削除し、クラス名上のカーソルとクラス全体の選択からのドットなしコピーを枠1・2へ統合する。通常のCtrl+C/Vは変更しない。
- 旧13の独立したスマート貼り付けも削除し、CSSでのドット付与・重複防止を枠1・2の貼り付けへ統合する。CSS自動配置は既存の専用コマンドを使う。
- 理由：利用頻度の低い操作を減らし、保存枠の状態と入口を下部に集める。

## 2026-10-26 — 設定全般への入口と枠の表示ON/OFF

- 下部の「Coding Tools Diff」を「Coding Tools」に変更し、クリックで全般設定メニューを開く。履歴はメニューから引き続き開ける。
- 枠1・2それぞれの番号、コピー／貼り付け表示、初期ショートカットキー、保存内容を独立して表示ON/OFFできる。表示は即時反映し再起動後も保持する。
- ON/OFFは表示だけを制御し、キーやコピー／貼り付け操作を停止しない。全非表示でも下部のCoding Toolsから復帰できる。
- 設定メニューとサイドバーの設定欄の両方から表示を変更できる。設定キャンセル時は変更しない。

## 2026-10-26 — CSS配置を枠1・2の貼り付けへ統合

- コピー枠1・2のクラスを、CSSの空いた構造位置へ貼ると配置候補を表示する。既存の同名ルールへジャンプするか、基本ルール／記述済み条件内へ空ルールを追加する。ファイルの自動切り替え・選択は行わない。
- 既存ルール自体を移動・変更しない。空ルールの追加は構文検査、差分確認、競合防止、Undoを維持する。
- 候補は一階層に並べ、Tab／Shift+Tabで選択しEnterで決定、Escで中止。マウスでの選択・実行も可能にする。
- コメント内・文字列や値・他言語にはドットを付けない。CSSのセレクタ入力ではドットを1つ付けてその場へ貼る。
- 新規@media作成、任意セレクタ入力、通常貼り付けを選ぶ画面と独立配置コマンドを削除する。通常のCtrl+C/Vは変更しない。
- HTMLの前後クラス情報は保存枠ごとに保持し、もう一方の枠をコピーしても混ざらない。
