# DATA_POLICY — データ・履歴の扱い

## データの種類

| 種類 | 保存対象 | リポジトリへ追加 |
| --- | --- | --- |
| 拡張のソース | JS・package.json・テスト | はい |
| 採用された構想・仕様 | Markdown | はい |
| デモ用GIF | 仮想画面だけの操作案内 | はい |
| 操作Diff | 個人/業務ファイルの変更差分 | **いいえ** |
| ファイル保存Diff | 保存時点の変更差分 | **いいえ** |
| Git push履歴 | 利用先のリポジトリ名等 | **いいえ** |
| 保存枠の文字列 | 個人・業務コードを含み得る | **いいえ** |

## デフォルトと制限

- 現行ソースでは、操作30日、ファイル保存90日、拡張内Git push90日を初期値とする。最大360日。
- OFFは以後の記録停止。旧ログを自動で全削除する意味ではない。
- 職場利用は会社規約・導入許可を優先。個人データを職場版に含めない。
- 将来、職場向けには履歴機能を**OFFにするだけでなくビルドから除外する**案を検討する。
- Gitで削除したファイルも過去のGit履歴に残る場合があるため、**初めから機密ログをコミットしない**。
