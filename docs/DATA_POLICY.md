# DATA_POLICY — データ・履歴の扱い

[開発方針へ戻る](VISION.md) / [今後の実装予定](ROADMAP.md)

## 作者による収集・送信を行わない

Coding Toolsは、利用者のコード・コピー内容・操作履歴を作者へ収集・送信しない。現在の実装にも作者への送信処理はなく、履歴は利用者の環境に保存する。作者が利用状況を中央で集計することを目的にしたデータ収集は行わない。

## 本人が履歴を使う目的

- 自分で選んだ記録をGPTなどへ渡し、レポート作成や振り返りに活用する。
- 操作が意図どおりにならなかったとき、簡易な差分履歴から変更箇所や原因を追う。
- 個人環境に合わせたカスタマイズや、機能拡張を検討する材料にする。

記録するかどうかは履歴設定で切り替えられる。外部サービスへ渡す記録は本人が選ぶ。現行版にGPTへの自動送信・自動レポート生成機能はない。

## 将来の版の分岐

作者への送信を行わない共通基盤から、本人が履歴を活用できる個人版と、履歴収集コードを含めない企業版を派生させる構想。企業版やプロジェクト別プロファイルの切り替えは未実装。

## データの種類

| 種類 | 保存対象 | リポジトリへ追加 |
| --- | --- | --- |
| 拡張のソース | JS・package.json・テスト | はい |
| 採用された構想・仕様 | Markdown | はい |
| デモ用GIF | 仮想画面だけの操作案内 | はい |
| 操作Diff | 個人/業務ファイルの変更差分 | **いいえ** |
| ファイル保存Diff | 保存時点の変更差分 | **いいえ** |
| Git push履歴 | 利用先のリポジトリ名等 | **いいえ** |
| 保存枠の文字列 | 個人・業務コードを含み得る | **いいえ** |

## デフォルトと制限

- 現行ソースでは、操作30日、ファイル保存90日、拡張内Git push90日を初期値とする。最大360日。
- 各履歴の保存期間から「OFF（記録しない）」または日数を選ぶ。OFFは以後の記録停止で、旧ログを全削除する操作ではない。日数を選ぶと記録を再開する。
- 職場利用は会社規約・導入許可を優先。個人データを職場版に含めない。
- 将来、職場向けには履歴機能を**OFFにするだけでなくビルドから除外する**案を検討する。
- Gitで削除したファイルも過去のGit履歴に残る場合があるため、**初めから機密ログをコミットしない**。
