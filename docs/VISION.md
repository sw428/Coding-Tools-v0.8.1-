# VISION — Coding Toolsの目的

## 個人学習

HTML/CSSの実装で繰り返す探索・コピー・移動・並び替えを補助し、ブラウザ上のレイアウトやカスケードの理解と検証に時間を残す。Diff履歴から誤判定を再現できるようにする。

## 将来の実務・チームワーク

共通エンジンを維持し、職場・案件ごとの命名規約、レイアウト方針、CSSの整理順序やメディアクエリの扱いを設定に分離する。判断基準と例外を視覚的に説明し、認識合わせと再作業のコストを減らす。

## 設計原則

1. **標準操作を守る**：Ctrl+C / Ctrl+Vを奪わず、専用操作として提供する。
2. **判断を残す**：自動配置の根拠を確認できるようにし、曖昧なら無断で破壊的変更しない。
3. **役割を分ける**：個人データ、職場データ、拡張機能のコードと仕様を混ぜない。
4. **使えるか測る**：時間、誤操作、Undo、メンテナンス負担で継続可否を決める。
5. **機能は削れる**：不安定な機能は無効化・分離・削除できるようにする。
6. **構想は仕様でない**：実装済み・検証済み・検討中を区別する。
