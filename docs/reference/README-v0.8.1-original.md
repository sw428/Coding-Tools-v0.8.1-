# Coding Tools v0.8.1 β — HTML/CSS用コピペ・CSS配置・Diff履歴

**β版・実機検証中。** VS Code **デスクトップ版**用の自作拡張。VSCodeVimは不要です。

> **通常のコピー・貼り付けはVS Code標準のまま。** Windowsの `Ctrl+C` / `Ctrl+V`、Macの `⌘+C` / `⌘+V` にはこの拡張のショートカットを登録していません。クラス名専用コピー、CSS自動配置、2枠コピー・貼り付けは専用コマンドで呼び出します。これにより標準のコピー・貼り付けを拡張側が乗っ取ることを避けています。

> **設定方針：ユーザーの `settings.json` を汚さない。** 履歴のON/OFF・保存期間・最終確認のON/OFFは **VS Code拡張機能専用の `globalState`** に保存します。Coding Toolsがユーザー・ワークスペースの `settings.json` に書き込むことはありません。ログの `.json` は「操作日時などのメタ情報」で、VS Codeの `settings.json` とは別です。

## インストール・最初に開く画面

1. VS Codeの拡張機能（Windows `Ctrl+Shift+X`、Mac `⌘+Shift+X`）→ 右上「…」→ **VSIXからのインストール**を選択。
2. `coding-tools-four-slot-0.8.1.vsix` を選び、必要ならコマンドパレットから **Developer: Reload Window** を実行。
3. `Ctrl+Alt+H`（Mac `⌘+Option+H`）またはステータスバー右下「Coding Tools Diff」で履歴を開く。
4. 同じエクスプローラーにある **Coding Tools 設定**を開き、ON/OFFや保存期間を変更。表示されない場合は `Ctrl+Shift+P` → **Coding Tools: 履歴・最終確認の設定を開く** を実行。
5. **Coding Tools: アニメーション付き使い方ガイドを開く** からVS Code内にSVGガイドを表示できます。

## 設定（ユーザーのJSONファイルを編集しない）

| 設定画面の項目 | 初期値 | 変更方法 |
|---|---|---|
| 操作ごとのDiffを記録 | **ON** | クリック・Enterで切り替え |
| ファイル保存時のDiffを記録 | **ON** | クリック・Enterで切り替え |
| Coding Toolsで行ったGit pushを記録 | **ON** | クリック・Enterで切り替え |
| CSS適用前の最終確認 | **ON** | クリック・Enterで切り替え |
| 操作履歴の保存期間 | **30日** | 7 / 14 / 30 / 60 / 90 / 180 / 360日、または自由入力 |
| 保存履歴の保存期間 | **90日** | 同上 |
| Git push履歴の保存期間 | **90日** | 同上 |

各履歴の保存期間は**1〜360日（360日が上限）**。設定変更は拡張の内部データに保持。OFFにしても既存ログは即削除せず、期間に応じた整理で削除します。

**例外の説明：** CSSファイルの優先候補や接頭辞別の配置規則について、旧版の `codingTools.preferredStylesheet` / `codingTools.placementRules` を**読み取る互換処理**はあります。拡張機能自身はこれらを `settings.json` に書き込みません。既存の任意設定はユーザー自身が管理してください。

**ショートカット設定**はVS Code標準のキー割り当て画面から変更できます。これは拡張のON/OFF設定とは異なり、キーをカスタマイズした場合はVS Code自身が `keybindings.json` に保存します（拡張機能が直接変更するものではありません）。

## コピー・貼り付け・クラス移動

**標準の `Ctrl+C` / `Ctrl+V`（Mac: `⌘+C` / `⌘+V`）は拡張機能による上書きなし。** ドット補完やクラス判定・操作Diffの記録は、専用の2枠コマンドやスマート貼り付けなどを使用した場合の機能です。通常のコピペは通常のテキストとして動作します。


| 機能 | Windows | Mac |
|---|---|---|
| **保存枠1〜2へコピー** | `Ctrl+Alt+Shift+1〜2` | `⌘+Option+Shift+1〜2` |
| **保存枠1〜2から貼り付け** | `Ctrl+Alt+1〜2` | `⌘+Option+1〜2` |
| 次のクラス名を全選択 | `Ctrl+Alt+J` | `⌘+Option+J` |
| 前のクラス名を全選択 | `Ctrl+Alt+K` | `⌘+Option+K` |
| **HTML → CSS定義へ移動** | **`Ctrl+Alt+3`** | **`⌘+Option+3`** |
| **CSS → HTML使用箇所へ移動** | **`Ctrl+Alt+4`** | **`⌘+Option+4`** |
| 次のクラスを選択に追加 | `Ctrl+Alt+Shift+J` | `⌘+Option+Shift+J` |
| 前のクラスを選択に追加 | `Ctrl+Alt+Shift+K` | `⌘+Option+Shift+K` |
| クラス名をコピー（ドットなし） | `Ctrl+Alt+Shift+C` | `⌘+Option+Shift+C` |
| CSSへ整理して追加 / 既存へ移動 | `Ctrl+Alt+P` | `⌘+Option+P` |
| 貼り付け方法を選択 | `Ctrl+Alt+V` | `⌘+Option+V` |
| 履歴パネルを開く | `Ctrl+Alt+H` | `⌘+Option+H` |

コマンドパレットの **Coding Tools: スマートコピー / CSSスマート貼り付け** も利用可能ですが、**初期状態ではキー未割り当て**です。必要ならショートカット一覧から任意のキーを割り当ててください。標準の `Ctrl+C` / `Ctrl+V` に割り当てるのは推奨しません。

**ショートカット一覧：** `Ctrl+K` → `Ctrl+S`（Mac `⌘+K` → `⌘+S`）→ 検索欄に **Coding Tools**。キー未設定のコマンドも検索して割り当て可能。拡張の設定欄「キーボードショートカット一覧を開く」でも一覧へ移動できます。

HTML の `class="card active"` では `card` → `active` → 次の class 属性の1語目、と順番に**単語全体を選択**。空の `class=""` は飛ばします。CSSでは `.card` などのクラスを全選択。連続した複数のクラスを同時選択したい場合だけ、別の「追加選択」コマンドを使います。

**専用コマンド・2枠コピペ**では、検索用には `card`、CSSセレクタ用には `.card` にする機能があります。標準の `Ctrl+V` では自動補完しません。ただしクリップボードが後から別の内容に変わるなど、クラスとして識別できない場合は専用のスマート貼り付けでも通常どおり貼り付けます。CSSへ整理するのは明示コマンドで選択できます。


## HTML ⇄ CSS相互ジャンプ（v0.8.1 β：エディタ内で直接移動）

1. `Ctrl+Alt+J/K` で次・前のクラス名を**全選択**。空の `class=""` は除外します。複数選ぶ場合は追加選択（`Ctrl+Alt+Shift+J/K`）。手動の選択範囲拡大でも使用可能です。
2. HTMLで `Ctrl+Alt+3`（Mac `⌘+Option+3`）ならCSSへ、CSSで `Ctrl+Alt+4`（Mac `⌘+Option+4`）ならHTMLへ**直接移動**。**確認画面・候補一覧を出さない**、読み取り専用のジャンプです。
3. 候補が複数なら、周囲のクラス名の一致・同じフォルダー・通常ルールとメディアクエリの条件などを参考に並べ、**最優先候補のコードをエディタで選択**します。順位は推測であり、正しさを保証しません。
4. ジャンプ後に **`Tab` で次の一致候補、`Shift+Tab` で前の候補**。右下に候補番号と移動先の案内を表示します。**`Esc` で候補巡回を終了**。終了すれば`Tab`は通常のインデントに戻ります。別の位置をクリック・編集した場合も候補巡回を解除します。
5. 候補が1件しかなければそのまま選択して終了。0件ならステータスバーで短く通知し、編集はしません。

**誤操作を避けるため、相互ジャンプはファイルの書き換えも確認ダイアログも行いません。** CSS追加・配置機能の確認画面は別の設定であり、今回の変更対象ではありません。既存の通常`Ctrl+C/Ctrl+V`も維持します。検索はワークスペース内の最大500ファイル（`node_modules`等は除外）。JavaScriptで動的に作るクラス、CSS Modules、CSSエスケープ名等は対象外です。

## CSSの自動配置と安全性

HTMLの前後・既存のCSS・親子/兄弟/状態・メディアクエリなどを考慮し、既存セレクタがあれば移動候補、新規なら関連グループ内の位置を提案。`@media`, `@supports`, `@container`, `@layer` が異なる場合は自動で混ぜず、候補を選びます。

選択画面は **↑↓：候補移動 / →：ON / ←：OFF / Enter：確定 / Esc：中止**。互いに排他的な候補は同時ON不可。別の最終確認ダイアログは拡張内部の設定でOFFにできます。変更はVS Codeエディタの通常Undo（Windows `Ctrl+Z`、Mac `⌘+Z`）で取り消せます。

## 3種類の履歴と月別フォルダー

```text
coding-tools-history/
  01_操作履歴/
    2026-10/
      日時-識別子.diff
      日時-識別子.json
  02_保存履歴/
    2026-10/
  03_Git履歴/
    2026-10/
```

- **操作：** 拡張経由の1回の編集ごとにDiffを記録。ファイルを保存したかどうかとは**別**です。単にコピーしただけでは記録しません。
- **保存：** 保存前の基準データと保存後のファイルとの差を記録。対象は開いているローカルファイル。
- **Git push：** **「Coding Tools: Git pushを実行して履歴を記録」** コマンドからpushし、成功した場合に履歴を記録。**通常のターミナル等で行ったpushは検知しません**。
- 履歴はVS Code右下の **Coding Tools Diff** / `Ctrl+Alt+H` / 履歴一覧からすぐ開けます。各Diffの右クリックから変更元ファイルへ飛べます。
- `*.diff` は変更行と周辺文脈、同名の `*.json` は記録日時・ファイル参照・操作内容など。**変更した内容に機密情報が含まれると、ログにも残ることがあります。**
- 古いログの整理は、起動時・新規履歴記録時・24時間ごとの処理などで行います。VS Codeを閉じている間の削除は次回起動時。**削除後の履歴は拡張機能から復元できません。** 必要なものはGit等で別途保存してください。

## テストと限界

`npm test` はパーサー・候補分岐・保存/履歴・内部設定の自動テストを実施します。VSIX生成：`python build-vsix.py`。**Windows/MacのVS Code実機での最終操作確認は未実施**のため、重要な案件では小さいテストファイルから使ってください。

CSSカスケードやすべてのネスト構文を完全解析する保証はありません。レイアウトの見た目はDevToolsで確認。操作DiffはGitの正式な履歴やバックアップの代わりではありません。VS Code外部からの通常コピーや通常Git pushを無条件に追跡するわけではありません。

**旧版から更新する場合：** 旧版が登録していた `Ctrl+C` / `Ctrl+V` の標準キーへの割り込みは、v0.8.1 βから削除しています。ただし過去に自分で `keybindings.json` へ割り当てた場合、それは残るためVS Codeのキーボードショートカット画面で確認してください。
