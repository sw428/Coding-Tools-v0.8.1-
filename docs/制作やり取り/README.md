# 制作やり取り — 記録の入口

Coding Toolsの開発中に交わした**制作上の相談・仕様変更・判断理由**を残す場所です。Wikiの`CURRENT.md`と同じ方針で、採用済み仕様と構想を分けます。

- [`制作ダイジェスト.md`](制作ダイジェスト.md)：**公開候補**。制作の変遷を技術的に整理した内容。公開前に再確認してください。
- `非公開_詳細記録/01_時系列_制作会話.md`：**個人保管用**。会話の原文抜粋＋編集要約。Git管理から除外します。
- `非公開_詳細記録/02_決定と未確定.md`：**個人保管用**。採用・撤回・未実装を区別。
- [`../公開前チェック.md`](../公開前チェック.md)：ソース／VSIX／会話ログの公開可否チェック。

## 取り扱い

**詳細な会話記録はGitに追加しない。** `.gitignore`で保護しています。公開用は技術的な制作経緯だけに絞っています。

このフォルダーに保存するファイルは、発言の記録と製品の現行動作を区別します。実装状態の正本は`CURRENT.md`と実際のソース・テストです。

個人保管用ファイルはGitでバックアップされないので、必要なら別の私的な保存場所にも保管してください。
