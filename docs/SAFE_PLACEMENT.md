# CSS配置 — v0.8.2 β

## 操作の流れ

1. 今開いているCSSの空行で、コピー枠1・2からクラスを貼り付ける。
2. 同じ適用範囲の既存ルールへ自動で移るか、コメントのまとまりへ空ルールを追加する。対応する目印がなければ登録書式で作り、領域不明・共用の場合は仮置き用の目印を使う。
3. 空ルール追加の場合は構文と挿入前後の構造を検査し、そのまま追加する。候補画面・差分プレビュー・追加の確認は出さない。`automaticPaste`をOFFにした場合だけ、従来の候補画面を使う。
4. Ctrl+Z（MacはCmd+Z）で追加を戻せる。操作履歴がONなら、追加後の差分は履歴から確認できる。

## 処理の範囲

- 既存ルールの移動・削除・書き換えは行わず、空ルール1件と、設定に登録されたCSSコメント最大1件を追加する。コメントを追加する場合も内容を照合し、登録外のコメント・宣言・追加ルールを拒否する。
- 記述済みの条件内へ追加できる。新規@mediaや独自セレクタの入力操作は設けない。
- 構文解析に失敗した場合や処理中にCSSが変更・閉鎖された場合は追加しない。新しい目印を作る設定がOFFで対応するまとまりもない場合も追加しない。
- 構造を変更する追加はCSSのみ。SCSS／Lessはその場への文字列貼り付けに対応する。
- 最終確認のON/OFF設定は削除した。実機での動作確認は未完了。

登録コメントと保持情報の選択は [WORKFLOW_SETTINGS.md](WORKFLOW_SETTINGS.md) に記載する。新規メディアクエリは作成しない。
