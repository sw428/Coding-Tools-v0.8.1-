# SPEC — 現行採用仕様と未実装案の境界

> **基準 v0.8.2 β**。現行コードと付属テストに基づく。ユーザー環境での実機検証は未完了。

## ナビゲーション

- HTMLのclass属性は空白区切りのトークン単位で移動。空の値は飛ばす。
- CSSはクラスセレクタを対象に前後へ移動。対象名全体を選択する。
- 前・次のクラス：Windows Ctrl+Alt+J / K。Mac Cmd+Option+J / K。
- HTML→CSS：Ctrl+Alt+3。CSS→HTML：Ctrl+Alt+4。
- 複数のジャンプ候補：最初の候補をエディタで開き、Tab / Shift+Tabで巡回。Escで終了。確認モーダルは出さない。

## コピーと貼り付け

- コピー保存枠は1・2の2つ。Windows Ctrl+Alt+Shift+1/2でコピー、Ctrl+Alt+1/2で貼る（MacはCmd+Option）。
- 下部ステータスバーは、枠ごとに「(番号) コピー（初期キー） 貼り付け（初期キー） / 保存内容」の順に表示。コピー／貼り付けは直接クリックで実行し、番号や保存内容のクリックでは操作メニューを開く。空枠の操作メニューはコピーのみ。
- 枠1・2それぞれで番号・操作名・初期ショートカットキー・保存内容を独立して表示ON/OFFできる。操作名とキーを両方OFFにするとコピー／貼り付けの表示は隠れる。非表示でも専用キーは動作し、保存内容は消さない。
- 下部の「Coding Tools」は設定全般の入口。表示項目の複数選択、履歴期間、最終確認、CSS設定、ショートカット、ガイド、履歴に進める。全非表示でもこの入口から表示を戻せる。
- 表示設定はglobalStateに保存し、即時反映する。サイドバーの設定欄からも変更できる。メニューをキャンセルした場合は変更しない。
- 選択したクラス名、またはカーソル上のクラス名をドットなしで保存。クラス以外の選択はそのまま、クラス以外で未選択なら現在行を保存する。
- 枠1・2の貼り付けは、CSSのセレクタ入力ではクラス名にドットを1つ付ける。CSSのコメント（/* */、編集中の//）、文字列・宣言値や他言語へはドットを付けない。CSSの空行では下記の配置候補を選ぶ。一般テキスト・CSSブロックなどは変換しない。SCSS / Lessはその場への貼り付けのみ。
- 枠のコピー・貼り付けはショートカットを維持し、コマンドパレットからは非表示。旧9〜13の独立した枠選択・クラス名コピー・スマートコピー／貼り付けは削除。
- **通常のCtrl+C / Ctrl+V、MacのCmd+C / Cmd+Vは上書きしない。**

## CSS配置

- コピー枠1・2のクラス名をCSSの構造上の空行へ貼り付けると、今のCSSファイルで配置候補を表示する。別ファイルの選択や自動切り替えは行わない。
- 候補は既存の同名ルールへのカーソル移動、基本ルールへの空ルール追加、記述済みの@media / @supports / @container / @layer内への空ルール追加。1つの一覧でTab／Shift+Tab・Enter、またはマウスで選択・実行できる。Esc・画面を閉じる操作で中止する。
- 新規@media作成、任意セレクタの入力、通常貼り付けを選ぶ画面、独立配置・貼り付け方法コマンドは削除。
- 空ルールを追加する場合も自動確定せず候補を選ぶ。HTMLの前後クラスは保存枠ごとに保持して配置候補に使う。選択中にCSSが変更・閉鎖された場合は中止する。既存ルールの移動・変更は行わない。
- 自動配置の判定は**安全性検証が必要なβ機能**。判断根拠が確定できない場合は安全側に倒す。

## 履歴と設定

- 拡張機能の操作ごとのDiff、ファイル保存ごとのDiff、**Coding Tools経由で成功したGit push**を別区分で保存。
- 各履歴の保存期間から「OFF（記録しない）」または1〜360日を選択。日数を選ぶと、その期間で記録を開始・再開する。独立した記録ON/OFF行は置かない。初期値：操作30日、保存90日、Git push90日。
- OFFは新しい記録を停止し、保存済みの保持日数は変更しない。期間選択のキャンセルでは設定を変更しない。CSS適用前の最終確認は独立したON/OFF項目として残す。
- 履歴ON/OFF・保持日数・最終確認は現行版では**globalState**に保存。利用者のsettings.jsonには書き込まない。
- `codingTools.placementRules` はVS Codeの設定項目として存在し、候補の初期選択に使う。ファイル選択を伴う`codingTools.preferredStylesheet`は削除。

## まだ採用済みの動作ではないもの

- 操作履歴などのON/OFF・保存日数を **UIとsettings.jsonのどちらからも変更・同期**する機能（要実装）。
- CSS解析を複数モジュールに分け、職場プロファイルの規約で制御する機能（設計段階）。
- 外部Gitクライアントで行ったすべてのpushを自動検知する機能（未実装）。

上記の未実装案を新機能として導入する際は `DECISIONS.md` と `CURRENT.md` を更新してからソースを変更する。
