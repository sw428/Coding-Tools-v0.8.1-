クラス選択

01次のクラス名を選ぶ（Win: Ctrl + 2 / Mac: Cmd + 2）＋

キーを押すたびに、次のクラス名へ選択が移ります。

  1. card を選択している状態
  2. Ctrl + 2 を押す
  3. もう一度押すと、次の行へ
  4. さらに押すと card__text へ

02前のクラス名を選ぶ（Win: Ctrl + 1 / Mac: Cmd + 1）＋

後ろから前へ、クラス名を1つずつ選べます。

  1. card__text を選択している状態
  2. Ctrl + 1 で1つ前へ
  3. もう一度押すと is-active へ
  4. もう一度押すと card へ

  2. Ctrl + Tab を押す
  3. もう一度押すと循環する

コピー・貼り付け

05保存枠1へコピーする（Win: Ctrl + Alt + Shift + 1 / Mac: Cmd + Alt + Shift + 1）＋

選択した文字やカーソル上のクラス名・ID名を枠1に保存します。クラスは`.名前`、IDは`#名前`で保存し、種別も内部で保持します。CSS以外へ貼るときは記号を外します。

  1. 保存したい文字を選択
  2. Ctrl + Alt + Shift + 1 を押す
  3. 枠1にはドット付きで保存される
  4. 枠の表示をOFFにしても、同じコピーキーで保存できる
GIFは自動で繰り返します。GIFを単独で開く ↗

コピー枠の表示は設定から変更できます。表示をOFFにしても、コピー・貼り付けのキー操作は使えます。

06保存枠1から貼り付ける（Win: Ctrl + Alt + 1 / Mac: Cmd + Alt + 1）＋

枠1の内容を貼り付けます。CSSでは位置に合わせてクラスに `.`、IDに `#` を付けます。検索欄では同じキーで検索語全体を名前だけに置き換えます。通常のCtrl+C／Ctrl+Vの内容は変えません。 Windowsでは他アプリにも同じキーで名前だけを貼れます。通常クリップボードは一時使用後に復元します。Macの外部貼り付けは未対応です。

  1. 先に保存枠1へコピーしておく
  2. HTMLでは名前だけ：card__title
  3. CSSのセレクタ入力ではドット1つ：.card__title
  4. CSSコメントの中ではドットを付けない
  5. CSS文字列の中ではドットを付けない
  6. CSSの宣言値でもドットを付けない
  7. ほかの言語でも名前だけを貼る
GIFは自動で繰り返します。GIFを単独で開く ↗

CSSのセレクタ入力ではドットを1つ付けます。HTML・コメント・文字列・宣言値・他言語では名前だけを貼ります。CSS空行への自動追加は「CSSへの追加」のGIFで確認できます。

  1. HTMLの card__title を選択
  2. Ctrl + Alt + 3 を押す

CSSへの追加

15CSSに空のルールを追加する（Win: Ctrl + Alt + 1 / 2 / Mac: Cmd + Alt + 1 / 2）＋

CSSの空行で枠1・2から貼ると、コピー元の構造と今のCSSから位置を決め、目印と空ルールを直接追加します。

  1. section内のクラスを先にコピーする
  2. CSSの空行で Ctrl + Alt + 1
  3. 目印の下へ直接追加される
  4. 目印がないCSSでも、同じキーで貼り付ける
  5. 登録した書式で目印を作り、その下へ追加する
  6. コピー元の領域が分からない場合
  7. 仮置きの目印を作り、その下へ追加する
GIFは自動で繰り返します。GIFを単独で開く ↗

既定は候補画面なし。領域が分からなければ仮置きの目印を作ります。既存コードは動かさず、Undoで戻せます。

16同名のCSSがあれば、その場所へ移動（Win: Ctrl + Alt + 1 / 2 / Mac: Cmd + Alt + 1 / 2）＋

同じ適用範囲に同じセレクタがあれば、追加せず既存箇所へ自動で移動します。

  1. CSSの空行で枠1・2から貼り付け
  2. 選択画面なしで既存の場所へ移動する
GIFは自動で繰り返します。GIFを単独で開く ↗
17既存の条件内へ追加する（Win: Ctrl + Alt + 1 / 2 / Mac: Cmd + Alt + 1 / 2）＋

記述済みの@mediaなどの空行で貼ると、その条件の範囲内へ空ルールを直接追加します。

  1. 記述済みの条件内の空行にカーソルを置く
  2. Ctrl + Alt + 1 で条件内に直接追加する
GIFは自動で繰り返します。GIFを単独で開く ↗

クエリーは自分で書きます。拡張は新しいクエリーを作りません。

18CSSを解析できなければ中止する（Win: Ctrl + Alt + 1 / 2 / Mac: Cmd + Alt + 1 / 2）＋

構文が壊れているなど、安全に追加できない場合は編集を中止します。

  1. 閉じかっこが余っているCSSの空行にカーソルを置く
  2. 枠1・2からクラスを貼り付ける
  3. 自動では変更されない
GIFは自動で繰り返します。GIFを単独で開く ↗

設定

25Coding Toolsの設定を開く（下部のCoding Toolsをクリック）＋

下部のCoding Toolsから設定を開けます。操作ヘルプの表示はON/OFFに切り替えられます。

  1. 下部のCoding Toolsから設定を開く
  2. 「ヘルプの表示・表示時間」を選ぶ
  3. ON：クラス名にカーソルを置くと行末にヘルプが出る
  4. 表示が不要なら「Help: Enabled」のチェックを外す
  5. OFF：カーソルを置いても行末のヘルプは出ない
  6. 再びチェックすると、次の操作からヘルプを表示する
GIFは自動で繰り返します。GIFを単独で開く ↗

「ヘルプの表示・表示時間」→「Help: Enabled」で切り替えます。OFFでも移動・コピー・貼り付けの操作は使えます。既定の表示時間は2秒です。 コピー枠の番号・ボタン・初期キー・保存内容は「コピー枠1の表示」「コピー枠2の表示」で個別に変更できます。
