# TEST_CASES — 検証手順

## 自動テスト

```bash
npm test
```

初期リポジトリ作成時（2026-10-25）、Node.js v22環境で終了コード0、`All tests passed.` を確認。**VS Code実機の保証ではない**。

## 手動テスト（テスト用サンプルのみを利用）

- [ ] VSIXをインストールして再読み込みできる
- [ ] HTMLで次/前のクラスを選択し、空 `class=""` を飛ばせる
- [ ] CSSで次/前のクラスを選択できる
- [ ] HTML→CSS→HTMLを往復できる
- [ ] 定義が複数のときTab/Shift+Tabで候補が動き、Escで通常のTabに戻る
- [ ] コピー枠1・2が別々に保存される
- [ ] 通常のCtrl+C/Vは従来どおりに動く
- [ ] CSS配置を試し、複数メディア条件でも不用意な変更がない
- [ ] CSS追加後にCtrl+Zで変更が戻る
- [ ] 操作・保存・Git push履歴が3つの場所に分かれる
- [ ] 履歴OFFで新規記録が止まり、過去ログは消去されない
- [ ] 1〜360日の保持期間設定が有効
- [ ] 別のVS Code拡張とショートカットが衝突しない

## 記録する情報（不具合が起きた場合）

- 日時 / OS / VS Code版 / Coding Tools版
- 使用したコマンドとショートカット
- 操作前のHTML/CSS（機密情報を除く最小再現例）
- 期待結果 / 実際の結果
- Diff、Undoの可否、再現頻度
- 暫定対応と判定（修正・機能OFF・保留）

`fixtures/`に安全なサンプルを置いた。実際の職場データは使用しない。
