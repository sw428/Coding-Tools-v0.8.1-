# TEST_CASES — 検証手順

## 自動テスト

```bash
npm test
```

初期リポジトリ作成時（2026-10-25）、Node.js v22環境で終了コード0、`All tests passed.` を確認。**VS Code実機の保証ではない**。

## CSS安全モード（v0.8.2）の重点テスト

- [ ] CSSへ新規クラスを追加すると、変更前後のDiffプレビューが表示される
- [ ] Diffで「差分を確認して適用」を選ぶまでCSSは変更されない（最終確認ONの場合）
- [ ] 最終確認OFFでも構文チェックを必ず通る
- [ ] CSSが不正な状態では挿入を中止する
- [ ] `@media` 内へ空ルールを追加しても、既存宣言は変更されない
- [ ] 既存の複雑なネスト・不明な構文では挿入を停止する
- [ ] SCSS / LESSへの自動挿入を拒否する
- [ ] プレビュー中に元ファイルが変更されたら適用しない
- [ ] `Ctrl+Z`で挿入を取り消せる
- [ ] 通常`Ctrl+C` / `Ctrl+V`は標準動作

## 手動テスト（テスト用サンプルのみを利用）

- [ ] VSIXをインストールして再読み込みできる
- [ ] HTMLで次/前のクラスを選択し、空 `class=""` を飛ばせる
- [ ] CSSで次/前のクラスを選択できる
- [ ] HTML→CSS→HTMLを往復できる
- [ ] 定義が複数のときTab/Shift+Tabで候補が動き、Escで通常のTabに戻る
- [ ] コピー枠1・2が別々に保存される
- [ ] 下部の「Coding Tools」にDiffが付かず、クリックして設定全般を選べる
- [ ] 下部ステータスバーに枠1・2の番号・コピー・貼り付け・キー・保存内容が表示される
- [ ] 枠1・2の各表示を独立してON/OFFでき、即時反映・再読み込み後の復元が行われる
- [ ] 設定メニューのチェック選択とサイドバー設定のON/OFFが一致する
- [ ] 全表示をOFFにしてもキー操作は動作し、Coding Toolsから表示を戻せる
- [ ] 番号・保存内容を押すと操作選択、コピー／貼り付けを押すと直接実行になる
- [ ] 枠をクリックしてコピー／貼り付けでき、キャンセルでは内容やコードが変わらない
- [ ] 空枠はコピーのみを選べ、エディタがない場合は保存内容が変わらない
- [ ] クラス上のカーソルとクラス全体の選択から、枠1・2へドットなしでコピーできる
- [ ] 枠1・2からCSSへ貼るとドットが1つ付き、HTMLへは名前だけが入る
- [ ] CSSの直前にドットがあっても重ならず、一般テキストはそのまま貼り付ける
- [ ] 枠のコピー／貼り付け4項目がコマンドパレットに表示されず、既存の専用キーは使える
- [ ] 旧9〜13と追加選択のコマンド／キーが削除されている
- [ ] 通常のCtrl+C/Vは従来どおりに動く
- [ ] CSSの空行で枠1・2から貼り付けると、同じCSSファイルの移動／空ルール追加候補が出る
- [ ] ファイル選択・通常貼り付けの別選択・新規@media・任意セレクタ入力が出ない
- [ ] 記述済みメディアクエリの候補が同じ一覧に並び、Tab／Shift+Tab・Enterで選べる
- [ ] マウスで候補を選び、実行ボタンを押せる。Esc・キャンセルで無編集終了する
- [ ] CSSコメント・文字列・宣言値では候補を出さず、ドットなしでその場へ貼る
- [ ] 候補選択中にCSSを変更・閉鎖すると追加しない
- [ ] 基本ルールへの追加が既存のネストしたルール内に入り込まない
- [ ] 枠1・2のコピー元情報が混ざらず、複数メディア条件でも不用意な変更がない
- [ ] CSS追加後にCtrl+Zで変更が戻る
- [ ] 操作・保存・Git push履歴が3つの場所に分かれる
- [ ] 操作・保存・Git pushの各保存期間メニューからOFFを選び、新規記録が止まる
- [ ] OFFを選んでも保存済みの保持日数は変わらず、過去ログの一括消去は行わない
- [ ] OFFの状態から日数または任意の日数を選び、その期間で記録を再開する
- [ ] メニューや日数入力をキャンセルしても、OFF状態と保持日数は変わらない
- [ ] 1〜360日の保持期間設定が有効
- [ ] 別のVS Code拡張とショートカットが衝突しない

## 記録する情報（不具合が起きた場合）

- 日時 / OS / VS Code版 / Coding Tools版
- 使用したコマンドとショートカット
- 操作前のHTML/CSS（機密情報を除く最小再現例）
- 期待結果 / 実際の結果
- Diff、Undoの可否、再現頻度
- 暫定対応と判定（修正・機能OFF・保留）

`fixtures/`に安全なサンプルを置いた。実際の職場データは使用しない。
